# OPTIONAL — only after Cloudflare is live and every DNS record for the site
# shows the orange cloud (Proxied). See README step 3.
#
# Your server IP is already public, so attackers can skip Cloudflare and hit
# the server directly. This makes Apache refuse any web request that didn't
# come through Cloudflare. Paste it directly under "# BEGIN HBL Hardening".
#
# Before relying on it:
#  - Compare these ranges with https://www.cloudflare.com/ips/ (they change rarely).
#  - Ask your host whether their SSL renewal (AutoSSL / Let's Encrypt) or
#    monitoring hits the site by IP. If so, add their IPs as extra
#    "Require ip" lines, or use Cloudflare's Origin CA certificate instead.
#  - If you get locked out, delete this block via the host's file manager/FTP.
#
# The stronger version of this is a server firewall rule (ask the host), and
# the strongest is also asking the host for a new IP once this is in place,
# since the current one is already known.

<RequireAny>
	# Cloudflare IPv4
	Require ip 173.245.48.0/20 103.21.244.0/22 103.22.200.0/22 103.31.4.0/22
	Require ip 141.101.64.0/18 108.162.192.0/18 190.93.240.0/20 188.114.96.0/20
	Require ip 197.234.240.0/22 198.41.128.0/17 162.158.0.0/15 104.16.0.0/13
	Require ip 104.24.0.0/14 172.64.0.0/13 131.0.72.0/22
	# Cloudflare IPv6
	Require ip 2400:cb00::/32 2606:4700::/32 2803:f800::/32 2405:b500::/32
	Require ip 2405:8100::/32 2a06:98c0::/29 2c0f:f248::/32
	# The server itself (WP-Cron and loopback requests)
	Require local
</RequireAny>
